# Побочные эффекты жизни — заметки для Claude Code

Браузерный симулятор жизни. Статический сайт без сборщика: `index.html` подключает классические скрипты по порядку, общее состояние лежит в глобальном `s`. Текущая сборка — 257.

## Как устроен код

- Функции расширяются цепочками обёрток: `const base={fn}; fn=function(){base.fn(); ...}`. Номер в имени файла (`finance43.js`, `habits78.js`) — версия, в которой модуль появился. Порядок `<script>` в `index.html` важен: обёртка видит только то, что загружено раньше неё.
- Ключевые точки: `advanceMonth` / `rollYear` (clock.js, game.js), `queueOnce` / `resolvePending` / `show` / `choose` / `log`, `remember` / `rel`, `save()` (обёрнут больше 30 раз, побочных эффектов в нём быть не должно).
- Страны: 25. Первые 14 (`nl rs ru us br jp fr es de uk ca kr cn mx`) есть во всех таблицах, 11 поздних (`it au tr za th no in id eg ma pl`) — не во всех. Новая страновая таблица должна покрывать все 25 или иметь явный запасной вариант.
- Офлайн-режим: каждый новый файл добавлять в `offline-assets.json` (одна строка, без пробелов) и поднимать имя кэша в `offline-worker.js`.

## Правила работы

- Новый код — отдельными файлами в стиле обёрток (`fixesNNN.js`, `pets-deathNNN.js`), подключать в `index.html` перед `bootstrap61.js`. Старые файлы трогать только точечно для настоящих багов и помечать комментарием `// NNN: ...`.
- При правке файла поднимать его `?v=` в `index.html` до номера сборки.
- Каждую сборку сопровождать `CHANGES-NNN.txt`: что исправлено, что сознательно не тронуто.
- Тексты игры — на русском, живым языком, без «игровой модели» и пересказа правил (см. раздел «Текст» в docs/ROADMAP.md).
- Формулы баланса проверять прогоном, а не на глаз.

## Проверка

```
python3 -m http.server 8765          # из папки с игрой
python3 tools/verify257.py           # точечные проверки сборки 257
python3 tools/run_lives.py out.jsonl 8 2 100 0.25 7   # N жизней, параллельно, до возраста, доля действий, сид
```

`tools/harness.js` внедряется в страницу: двигает время, отвечает на события, кликает случайные действия, ловит ошибки и NaN. Нужен Playwright (`pip install playwright && playwright install chromium`). Больше 2 жизней параллельно — браузер может падать по памяти; это ограничение прогонщика, а не баг игры.

## План работ

Полное ТЗ — `docs/ROADMAP.md`. Делаем слоями, каждый слой — отдельная рабочая сборка.

1. **Баги** — сделано в 257, кроме смертности.
   - Осталось: смертность. `deathChance257` в `fixes257.js` готова, но не подключена — в прогоне персонажи умирали в 50–52, здоровье падает быстрее, чем заложено. Сначала снять траекторию `s.health` по годам (прогон с `deathChance257=()=>0`), потом подобрать коэффициенты: цель — средняя продолжительность около 78 без заботы о здоровье и 85+ с заботой, до 60 не доживают 2–3%. Подключение — одна строка в `rollYear` в game.js.
2. **Тишина и видимость** — механики есть, их не видно: смерть питомца окном с прощанием, уведомления о питомцах не дома и питомцах близких, окно помёта, пояснения к праздникам, просьба ребёнка о питомце учитывает животных дома.
3. **Баланс** — гонорары и рост творческих уровней, выручка бизнеса, зависимости от курения и алкоголя.
4. **Новые системы по одной** — зеркальные просьбы детей и родителей (лагерь, школа, животное без спроса), подсказки о близких, уговоры партнёра и переезд к себе из другого города, транспорт, внешние события, интересы, страновые различия.
